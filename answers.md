## 1. What is inside the request object (`req`)?
The `req` object represents the HTTP request. It contains information such as request parameters, query strings, request body, and HTTP headers.

## 2. What is inside the response object (`res`)?

<!-- write your answer here -->
The `res` object represents the HTTP response sent by the Express app. It provides methods to send data, set status codes, and send JSON responses to the client.

## 3. What does `app.use()` do?

AI Summary

The `app.use()` method in Express.js is used to register and execute middleware functions within an application. These functions are code segments that run during the intermediate stage—from the moment an HTTP request is received from the client until the response is sent back to it.
